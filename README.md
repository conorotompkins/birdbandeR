# birdbandeR
A repo for maintaining a front-end data entry and validation system for bird banding.

## Workflow:

1. Master Bander defines data validation settings
     * https://github.com/conorotompkins/bird_banding_ui/issues/33
3. Define banding session
    *  https://github.com/conorotompkins/bird_banding_ui/issues/1
4. Deploy nets
5. Band birds
6. Enter banding data
    *  https://github.com/conorotompkins/bird_banding_ui/issues/2
7. Validate data
    * https://github.com/conorotompkins/bird_banding_ui/issues/34
8. Generate daily summary
